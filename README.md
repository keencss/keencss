# keen.css – The Algorithmic CSS Framework

CSS is a declarative programming language, and keen.css is the framework for using it to build robust and scalable design systems.

> [!WARNING]  
> This project is in the alpha stage. It is still under development, may contain bugs, or may change at any time.

## What does "Algorithmic CSS Framework" mean?

keen.css offers specialized algorithms that promote a harmonious overall appearance, but it does not dictate a specific design. The algorithms can be configured and extended. These different variants of an algorithm can be nested within one another when called from HTML.

## Principles and Goals of keen.css

- excellent developer experience across all skill levels
- reward semantic HTML
- promote accessible designs (a11y)
- carefully selected default values
- robust and scalable architecture
- suitable for one person as well as for an entire team
